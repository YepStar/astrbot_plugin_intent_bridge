# 冷月系—自然意图分析

把日常聊天里的需求，变成机器人真正执行的操作，不必记住一串指令。

## 可以做什么

- 说“帮我找本书”，让机器人调用已接入的搜书功能。
- 说“来一首歌”，使用音乐插件搜索和处理你的需求。
- 发图后说“把这个表情收藏起来”，交给表情功能保存。
- 在面板中选择允许接入的功能，查看实际调用记录。

## 如何使用

在 AstrBot 中安装本插件，然后从左侧扩展功能打开「（月）自然意图分析」，按面板提示完成设置。

需要先安装并配置对应功能插件。本插件负责理解和衔接，具体动作仍由原插件执行；原有权限与必要确认继续生效。

## 同系列插件

以下均由 **YepStar** 创作和维护，属于「冷月系」，可按需搭配使用。

- [并行记忆分支](https://github.com/YepStar/astrbot_plugin_memory_branches)：分别保存和整理不同对话的记忆。
- [Zlib知识库](https://github.com/YepStar/astrbot_plugin_zlib_knowledge)：找书、整理书架与知识库。
- [网易云音乐](https://github.com/YepStar/astrbot_plugin_netease_browser)：找歌、分享歌曲和一起听。
